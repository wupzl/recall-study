回想首个正式版本，为 Android 和 Windows 提供离线学习与回顾计时。

设置一次 1～90 分钟的学习后，应用会每隔随机 3～5 分钟播放短提示音，提醒闭眼回顾；20 秒后用另一种提示音提示继续，自动进入下一轮。回顾计入总时长，到点自动结束。

- 支持开始、暂停、继续、提前结束。
- 支持提示音试听与音量调节。
- 学习记录仅保存在本机，无需账号，手机与电脑独立使用。
- Android 支持切换应用、锁屏后继续计时，通知栏可暂停或结束。
- Windows 支持系统托盘运行，学习期间阻止自动睡眠，手动睡眠时暂停。

## 安装

- **Android 8.0+**：下载 `Recall-Study.apk` 安装。首次开始时允许通知和不受电池优化限制；请先试听，确认闹钟音量。部分品牌还需允许后台运行或自启动。
- **Windows 10 / 11**：下载 `Recall-Windows.zip`，解压后双击 `Recall-Study.exe`。程序未进行商业代码签名，Windows 可能显示未知发布者。
- `SHA256SUMS.txt` 提供 APK 和 EXE 的 SHA-256 校验值。

## 验证与已知限制

- Java、C# 两端计时引擎各通过 10,049 个自动检查。
- Windows 实际界面通过暂停、继续、托盘、20 秒回顾与记录保存检查。
- Android 15 模拟器通过完整 6 分钟锁屏会话，验证随机提醒、20 秒后自动继续、到点结束与记录保存；测试中还强制进入了深度休眠状态。
- 模拟器验证不能替代手机真机的提示音与厂商省电策略测试；首次使用请完成一轮锁屏测试。
- 强行停止、关机后无法继续提醒；异常中断记录最多可能少计最近约 5 秒。
