回想 v1.1.0 将短回顾节奏改为可自定义的学习与休息周期。

## 本次更新

- 默认每轮随机学习 **20～30 分钟**，然后随机安静休息 **5～8 分钟**，每轮重新抽取。
- Android 和 Windows 均可修改学习下限、学习上限、休息下限、休息上限；每项为整数 1～90 分钟，下限不大于上限。
- 上下限相同表示固定时长，例如学习 25～25 分钟、休息 5～5 分钟。
- 有效设置保存在本机，开始后锁定本次节奏，结束后可修改下一次节奏。
- 休息阶段提示“安静休息”，取消“闭眼回顾 20 秒”的流程；休息结束播放提示音并自动继续学习。
- 两阶段均可暂停、继续。总时长保持 1～90 分钟且包含休息；到点优先结束，最后一个阶段可能被截短。
- Android 通知栏、Windows 托盘和学习记录界面同步更新。

## 下载与升级

- **Android 8.0+**：下载 `Recall-Study.apk`，直接覆盖安装即可保留本机记录，无需卸载。版本号 1.1.0，继续使用原来的签名。
- **Windows 10 / 11**：从托盘退出旧版，解压 `Recall-Windows.zip` 后运行 `Recall-Study.exe`。原有本机记录保留，新增节奏采用默认值。
- 首次使用仍需允许 Android 通知和后台运行，建议先试听提示音。
- Windows 程序未进行商业代码签名，系统可能显示未知发布者。

## 验证

- Java 与 C# 计时引擎各通过 20,062 个断言，覆盖默认长时长、自定义范围、随机上下界、固定时长、暂停及总时长截断。
- Windows 原生界面使用可配置的 1 分钟学习 / 1 分钟休息，完成真实 3 分钟会话，覆盖设置迁移与保存、校验、托盘、两阶段暂停、自动继续与完成记录。
- Android 15 模拟器以相同短配置验证覆盖升级、设置保存与锁屏计时。模拟器不能替代手机真机对声音及厂商后台限制的验证。

默认时长是可调整的使用节奏，不代表适用于所有人的科学最优值。
